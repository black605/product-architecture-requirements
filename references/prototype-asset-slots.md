# 原型素材占位 Contract

用于黑白低/中保真原型中标注未来素材的位置与约束。它描述素材承担的业务语义、空间和状态，不生成或复用最终图片、插画、图标、音视频和品牌资源。

## 1. 触发条件

页面存在封面、人物、插画、图标、音频、视频、文档预览或其他视觉/媒体内容时，原型生成前建立 `ASC-`。只有纯文本和通用控件且布局不受素材影响时可标记 `not_applicable`。

## 2. Slot 必需字段

每个素材 Slot 至少定义：

- `slot_id`、页面、区域、语义角色和信息优先级；
- 素材类型、必需/可选、允许格式和来源状态；
- 宽高比、最小/最大尺寸、适配方式和安全区；
- 占位表达、替代文字、说明文字和交互；
- loading、empty、error、unavailable、extreme_content 状态；
- 缺失时保留、替换、禁用还是坍缩；
- `visual_flexible` 与 `forbidden_assumptions`。

详细结构使用 [`../schemas/asset-slot-contract.yaml`](../schemas/asset-slot-contract.yaml)。

## 3. 黑白占位规范

| 素材类型 | 原型表达 |
|---|---|
| 图片/插画/头像 | 灰色描边矩形或圆形，显示 Slot 名称、比例和状态 |
| 视频 | 比例框、播放语义和时长位置，不嵌入真实封面 |
| 音频 | 播放/暂停、时长和状态占位，不伪造波形或录音结果 |
| 图标 | 使用语义标签或通用线框符号，不复制品牌图标 |
| 文档预览 | 页面缩略框、文件类型和不可预览出口 |

占位符必须能被评审者识别为原型，不使用彩色品牌插画、历史项目素材或生成式装饰填满空白。

## 4. 缺失与状态规则

- P0 必需素材缺失时，不展示成功态；显示安全占位和下一步，例如重试、上传或返回。
- P1 缺失时保持主结构稳定，并提供简短替代说明。
- P2 或可选素材缺失时按 Contract 坍缩，不保留空卡片和断裂分隔线。
- 加载失败不能静默使用旧项目图片兜底；fallback 只能来自当前项目允许清单。
- 超长标题、极端比例和资源数量超限必须有裁切、contain、分页或数量上限规则。

## 5. 项目隔离

`source_asset_ids` 默认空。只有当前项目 Profile 明确授权的资产才能引用；历史项目 URL、Figma 图片填充、下载缓存和样例资源均不得自动进入 Slot。Slot Contract 可以继承比例和安全区规则，不能继承具体资源。

## 6. 验收

- 所有影响布局的素材位置都拥有 `ASC-` Slot；
- 原型只显示黑白占位和语义，不包含最终视觉资产；
- P0/P1/P2 缺失行为、加载和错误出口明确；
- 每个 Slot 绑定当前 `project_id`、页面、区域和 PUI；
- 旧项目资源不会作为自动 fallback；
- 设计师可以替换素材外观而不改变 Slot 语义和尺寸约束。
