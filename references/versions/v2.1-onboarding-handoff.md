# v2.1-onboarding-handoff

## 目标

让教师、业务专家和设计师无需先学习 PRD 术语即可开始使用，并让需求结果能够专业地交接给设计、开发、测试和验收角色。

## 关键补丁

- 增加想法变产品、痛点梳理、资料整理、设计输入和生产交接五种快速上手模式。
- 增加自然语言术语翻译和角色化开场。
- 增加 Ready/Done 生产门槛和设计/开发/验收交接包。
- 关键未确认规则必须显式保留，不得为了交付完整而静默假设。

## 验证标准

- 非专业用户首轮能看到可选择的下一步和回答示例。
- 设计师能直接获得页面、组件和状态输入。
- 开发/测试能获得功能、依赖、验收标准和风险清单。
