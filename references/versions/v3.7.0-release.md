# v3.7.0 项目级模具与对话原型发布基线

## 目标

在 v3.4.8 需求、PUI、DS 与交接能力之上，建立项目独立 UI Profile、原型前模具适配、无匹配候选、素材占位、对话式原型和模板生命周期，使新项目不会默认套用旧模具或继承旧内容。

## 版本能力

| 版本 | 能力 |
|---|---|
| v3.5.0 | ProjectUIProfile、UIEvidenceMap、项目隔离 |
| v3.5.1 | Template Catalog、七维适配和 exact/extensible/no_match |
| v3.5.2 | ASC 素材占位和 project-local PTC 候选 |
| v3.6.0 | PRS 对话式生成、受控 Generation Request、自然语言 Patch |
| v3.6.1 | TMF、验证、登记、版本、停用与返回审计 |
| v3.7.0 | 结构校验、跨项目回归、50 轮正式前向测试与中文发布说明 |

## 发布门槛

- `quick_validate.py` 通过；
- v3.4 生命周期 25 项检查全部通过；
- v3.7 原型模具体系 50 项结构检查全部通过；
- 跨项目、exact、extensible、no_match、对话 Patch 和登记生命周期用例通过；
- 正式运行时 50 轮完成，四维总分不低于 90；
- README、平台配置和 CHANGELOG 与当前规则一致；
- 未访问 Figma 时不声称已提取具体节点数据；
- 未授权时不执行 Catalog、Registry、Git 或部署写入。

## 证据边界

规则、Schema、结构检查和正式对话记录只能证明 Skill 的决策约束与运行表现；不能替代真实 Figma 提取、原型渲染、目标用户测试、模板目录登记、组件 Registry、工程消费或生产部署证据。
