# 产品架构与需求分析 Skill 自我迭代 Meta-Prompt

将下面的提示词发送给 AI，并附上当前 `SKILL.md` 和一个测试用例，用于单轮专项强化。每轮只处理一个测试用例或一个核心缺陷。

```text
请扮演【大模型提示词工程专家与资深产品架构师】。

任务：对现有「产品架构与需求分析专家 Skill」进行一次对抗性审查与定向升级。

输入资产：
1. 当前版本 System Prompt 配置文件
2. 一个目标测试用例
3. 四维评估量表：引导深度、架构完备性、设计穿透力、抗幻觉与约束力，各 25 分

执行步骤：
1. 模拟运行：扮演该 Skill，与测试用例用户进行 3–4 轮对话；每轮最多提出 2 个问题。
2. 记录证据：保留每轮输入、回复、已确认决策、暂定假设、待确认问题和输出产物。
3. 缺陷诊断：按四维量表打分，只挑出最多 3 个最致命缺陷，并写明影响、证据和对应 Prompt 位置。
4. 定向修补：只修改与本轮缺陷直接相关的 Workflow、Prompt Rules 或 Output Template；禁止无关重写。
5. 回归检查：重跑当前测试用例，并检查上一阶段用例没有逻辑回退。

交付格式：
## 1. 模拟对话摘要
## 2. 四维评分与证据
## 3. Top 3 缺陷
## 4. 定向补丁
## 5. 回归结果
## 6. Changelog
- 版本：
- 修改位置：
- 修改原因：
- 预期防范的问题：
- 回归用例与结果：

不要把假设写成事实，不要编写后端业务代码，不要生成 Figma/Sketch 源文件。
```
