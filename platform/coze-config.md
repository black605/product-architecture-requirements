# Coze 配置映射

## Bot 人设/系统指令

将上级目录的 `SKILL.md` 全文粘贴到 Bot 的人设与指令字段。将 `references/meta-prompt.md` 作为维护者测试时使用的独立指令，不作为普通用户默认开场白。

## 建议工作流节点

1. 输入节点：项目想法、已有资料、目标输出。
2. 对话节点：执行 5W2H 澄清，每轮最多 2 个问题。
3. 分析节点：输出业务流程、功能矩阵、IA、页面和组件规格。
4. 可选联网节点：只在用户要求对标或需要最新资料时启用。
5. 汇总节点：按 Output Template 生成交付物，并列出待确认项。

## 范围边界

不启用代码执行或源文件生成作为默认能力；技术架构只输出需求级候选方案。
