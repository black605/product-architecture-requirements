# 模具可扩展匹配回归

## 输入

当前项目与候选模具的目标用户、核心任务、页面类型、P0 区域、设备和主操作一致。当前页面额外需要一个可选的“学习建议”区域和一个 `partial_data` 状态；模具已经声明对应区域和状态扩展点。

## 期望

- 七个维度逐项检查，硬阻塞项全部通过；
- 结果为 `extensible`；
- `required_extensions` 明确记录新增区域、插槽和状态；
- 扩展发生在项目实例，不修改共享模具；
- P0、唯一主操作和现有异常出口保持不变。

## 失败信号

- 把任意视觉相似都判为可扩展；
- 为适配模具而隐藏 P0、移动主操作或删除错误出口；
- 扩展直接写回共享模具；
- 扩展时带入旧项目文案和资产。
