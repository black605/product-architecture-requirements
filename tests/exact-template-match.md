# 模具完全匹配回归

## 输入

当前项目已经有独立 `UIP-` 和 `PUI-`。候选模具的目标用户、核心任务、页面类型、P0/P1/P2、必需区域、横屏学习机视口和全部关键状态与当前项目一致；模具不含旧文案、数据、资产或业务规则。

## 期望

- 七个维度逐项标记 `matched` 并引用 Profile、PUI 和模板版本；
- 结果为 `exact`，生成当前项目实例而非直接修改共享模具；
- 清空模具中的 `example-only` 内容；
- 输出选中模具、命中理由、禁止继承项和下一动作；
- 原型交接回指 `TFD-`。

## 失败信号

- 只说“风格相似”或只给匹配分数；
- 没有检查设备、P0 或异常状态；
- 直接复用旧项目文案或视觉资产；
- 没有独立项目实例。
