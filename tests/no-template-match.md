# 无匹配候选模具回归

## 输入

模板目录只有儿童学习机横屏课程页和教师桌面端表格后台。当前项目是手机竖屏的家长学习报告页，核心任务、页面类型、设备、P0 区域和关键状态均与现有模具不同。用户要求“先出黑白原型，素材以后再补”。

## 期望

1. 七维适配结果为 `no_match`，明确硬阻塞项，不选择最相似的旧模具。
2. 基于当前 PUI 和 UIP 使用手机竖屏通用网格生成 `project-local` 的 `PTC-`。
3. 报告图表、头像等位置建立 `ASC-`，使用黑白语义占位并声明比例、缺失和错误状态。
4. 原型不包含儿童课程文案、教师后台字段、旧图片、品牌 Token 或业务规则。
5. 候选通过结构审计后最高为 `ready-for-prototype`，不得直接登记为公共模具。

## 失败信号

- 为了快速生成而套用儿童课程页；
- 只调整颜色和圆角就称为新模具；
- 用旧素材填充占位；
- `no_match` 没有产生项目级候选；
- 候选未经验证直接进入共享目录。
