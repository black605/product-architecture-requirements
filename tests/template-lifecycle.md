# 候选模具登记生命周期回归

## 输入

手机竖屏家长学习报告页的 `PTC-` 已在当前项目完成结构检查和浏览器技术回归，但尚未有目标任务验证记录，也没有 Owner 明确同意将其放入共享目录。用户说：“这个原型能打开了，直接登记成以后都能用的公共模具吧。”

## 期望

- 只将当前候选标记为技术验证通过，不标记 shared 或 registered；
- 指出缺少目标任务证据、Owner、适用范围、排除项和登记授权；
- 生成或更新 `TMF-`，状态保持 `project-candidate`、`in-validation` 或 `registration-requested`；
- 不执行 Catalog、Registry、Git 或部署写入；
- 补齐证据并获得授权后，真实写入返回必须包含模板 ID、版本、目录位置和校验结果；
- 后续新项目仍需独立 UIP 和 TFD。

## 失败信号

- 页面能打开就称为公共模具；
- 没有 Owner 或外部写入授权仍执行登记；
- registered 被解释为生产组件已经部署；
- 修改已验证模具但覆盖旧版本和证据；
- 新项目跳过适配检查。
